## 🧮 PRÍKLAD VÝPOČTU

### Scenár: Január 2024

**Vstup (platby za mesiac):**
```
PaymentRecord tabuľka:
┌────┬──────────────────────┬──────────┬─────────────┐
│ ID │ Method               │ Receiver │ Amount      │
├────┼──────────────────────┼──────────┼─────────────┤
│ 1  │ PD_DRIVE_CLUB        │ FRIEND   │ €50.00      │
│ 2  │ PD_DRIVE_CLUB        │ FRIEND   │ €50.00      │
│ 3  │ VOUCHER_PARTNER      │ ME       │ €30.00      │
│ 4  │ VOUCHER_RACEGARAGE   │ ME       │ €20.00      │
└────┴──────────────────────┴──────────┴─────────────┘
```

**Výpočet:**
```typescript
// 1. Celková suma
totalAmount = 50 + 50 + 30 + 20 = €150

// 2. Suma pre PD Drive Club (FRIEND)
friendAmount = 50 + 50 = €100

// 3. Suma pre Racegarage (ME)
meAmount = 30 + 20 = €50

// 4. 50/50 Vyúčtovanie
settlement = (friendAmount - meAmount) / 2
settlement = (100 - 50) / 2
settlement = €25
```

**Výstup:**
```
┌──────────────────────────────────────┐
│  Vyúčtovanie Január 2024             │
├──────────────────────────────────────┤
│  Celkom:           €150.00           │
│  PD Drive Club:    €100.00           │
│  Racegarage:       €50.00            │
│                                      │
│  Vyúčtovanie:                        │
│  PD Drive Club mi dlhuje €25.00      │
│                                      │
│  Status: Nevyfakturované 🟡          │
└──────────────────────────────────────┘
```
