│  🚀 3 KROKY K DATABÁZE                                       │
└──────────────────────────────────────────────────────────────┘

KROK 1: Otvorte terminál
        (Command Prompt / Terminal / PowerShell)

KROK 2: V priečinku projektu spustite:
        
        npx prisma studio

KROK 3: Otvorí sa prehliadač (http://localhost:5555)
        → Kliknite "PaymentRecord"
        → Pozrite stĺpec "receiver"

✅ HOTOVO! Vidíte všetky platby v databáze!

┌──────────────────────────────────────────────────────────────┐
│  🔍 ČO HĽADÁTE                                               │
└──────────────────────────────────────────────────────────────┘

V stĺpci "receiver" hľadajte:

┌────┬──────────────────────┬──────────┐
│ id │ method               │ receiver │
├────┼──────────────────────┼──────────┤
│ 1  │ PD_DRIVE_CLUB        │ FRIEND ✅│
│ 2  │ VOUCHER_PARTNER      │ ME ✅    │
│ 3  │ VOUCHER_RACEGARAGE   │ ME ✅    │
│ 4  │ VOUCHER_PD_DRIVE_... │ FRIEND ✅│
└────┴──────────────────────┴──────────┘

✅ SPRÁVNE: Mix ME a FRIEND

❌ PROBLÉM: Všetko je ME!
   → Pozrite sekciu "Ako Opraviť" nižšie

┌──────────────────────────────────────────────────────────────┐
│  📊 SPOČÍTAJTE                                               │
└──────────────────────────────────────────────────────────────┘

Koľko máte:
□ receiver = ME       (malo by byť ~60%)
□ receiver = FRIEND   (malo by byť ~40%)

Ak je všetko ME → PROBLÉM! Potrebujete opravu!

┌──────────────────────────────────────────────────────────────┐
│  🔧 AKO OPRAVIŤ (Keď Je Všetko ME)                          │
└──────────────────────────────────────────────────────────────┘

1. ZÁLOHA NAJPRV!
   
   pg_dump simulator > backup.sql

2. PRIPOJTE SA K DATABÁZE
   
   psql -U postgres -d simulator

3. SPUSTITE OPRAVU (2 príkazy):

   UPDATE "PaymentRecord"
   SET receiver = 'FRIEND'
   WHERE method = 'PD_DRIVE_CLUB'
     AND receiver = 'ME';

   UPDATE "PaymentRecord"
   SET receiver = 'FRIEND'
   WHERE method = 'VOUCHER_PD_DRIVE_CLUB'
     AND receiver = 'ME';

4. OVERTE ČI FUNGUJE

   SELECT receiver, COUNT(*)
   FROM "PaymentRecord"
   GROUP BY receiver;

   Mali by ste vidieť obe hodnoty (ME a FRIEND)!

┌──────────────────────────────────────────────────────────────┐
│  ✅ TESTOVANIE PO OPRAVE                                     │
└──────────────────────────────────────────────────────────────┘

1. Vytvorte novú platbu v aplikácii
   Dashboard → Zaznamenať jazdu → PD Drive Club

2. Overte v Prisma Studio (F5 refresh)
   Nová platba by mala mať receiver = FRIEND

3. Overte v aplikácii
   Platby → "Celkom pre kamaráta" by sa malo zvýšiť
